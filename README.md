# Tugas Praktikum Python Semester 5

Kumpulan program Python untuk latihan dasar pemrograman dan pengolahan data pada praktikum. Program-program berikut dijalankan secara terpisah dan sebagian meminta input melalui terminal.

## Daftar program

| File | Deskripsi |
| --- | --- |
| `1.py` | Latihan input dan output sederhana. |
| `biodata.py` | Menampilkan contoh biodata dengan informasi pribadi disamarkan. |
| `diskon_biaya.py` | Menghitung diskon biaya kuliah berdasarkan IPK, status anak karyawan, dan pembayaran tepat waktu. |
| `menu_si_mahasiswa.py` | Menu interaktif untuk mengecek status mahasiswa, menghitung diskon, dan melihat peringatan stok barang. |
| `peringatan_stok.py` | Mengelompokkan kondisi stok barang dan merangkum kebutuhan restock. |
| `ringkasan_algoritma.py` | Menghitung ringkasan status mahasiswa, rata-rata diskon, dan persentase item yang membutuhkan restock. |
| `status_mahasiswa.py` | Mencatat dan menampilkan status akademik mahasiswa. |
| `validasi_data.py` | Memvalidasi NIM, IPK, SKS, dan semester. |

## Persyaratan

- Python 3
- Tidak memerlukan library tambahan; semua program menggunakan pustaka standar Python.

## Menjalankan program

Buka terminal di folder proyek, lalu jalankan file yang diinginkan:

```powershell
py menu_si_mahasiswa.py
```

Ganti `menu_si_mahasiswa.py` dengan nama file program lain. Untuk beberapa program, ikuti instruksi dan masukkan data yang diminta di terminal.
